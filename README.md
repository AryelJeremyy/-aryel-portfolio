# Aryel — Portfolio Site

## What's in here
- `index.html` — the whole site (HTML/CSS/JS in one file)
- `assets/` — real screenshots from the Coach Maya project

## Before you publish — fill these in
Search `index.html` for these placeholders and replace them:
- `RESUME-LINK-HERE` — link to your resume (PDF, Google Drive, etc.)
- `LINKEDIN-LINK-HERE` — your LinkedIn URL
- `GITHUB-LINK-HERE` — your GitHub URL
- `YOUR-EMAIL-HERE` — your email address
- `ONLINEJOBS-LINK-HERE` — your OnlineJobs.ph profile URL

## Deploy to GitHub Pages (free)
1. Create a new GitHub repo, e.g. `aryel-portfolio`
2. Upload `index.html` and the `assets/` folder to it (drag-and-drop works on github.com, or use git)
3. Go to the repo's Settings then Pages
4. Under "Source," select the main branch and root folder, then Save
5. GitHub gives you a live URL in a minute or two: https://<your-username>.github.io/aryel-portfolio/

That URL is what you put in the "portfolio website" field on job applications.
